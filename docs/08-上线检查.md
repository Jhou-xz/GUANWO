## A. 必须（上线前逐条勾）

### 环境变量（见 `.env.example`）
- [ ] `DEEPSEEK_API_KEY` —— 仅服务端注入，绝不进前端 bundle。缺失则 AI 路由 500。
- [ ] `DATABASE_URL` —— 托管 Postgres 连接串。**生产缺此值进程会拒绝启动（exit 1）**，
      以防误用本地 PGlite 导致多实例数据分裂 / 无盘容器丢数据。
  - PgBouncer 的 transaction 池：连接串加 `?pgbouncer=true`，并在 `createPgDb` 里设 `prepare: false`。
- [ ] `WECHAT_APPID` / `WECHAT_SECRET` —— 配齐才开微信登录入口；secret 只在服务端。
- [ ] `WECHAT_REDIRECT` —— 回调地址，须在微信后台「网页授权域名」白名单内。
- [ ] `NODE_ENV=production` —— 触发生产兜底（缺库即拒启）。
- [ ] `PORT` —— 默认 8787，按平台调整。

### 数据库
- [ ] 用**托管 Postgres**（RDS / Neon / Supabase 等），不要本地 PGlite。
- [ ] 开启**自动备份 + PITR**（时间点恢复）。命盘是用户核心资产，丢不得。
- [ ] 迁移：表结构由 `drizzle/` 迁移管理，**启动时自动 `migrate()`**（幂等，已应用的跳过）。
      首次连**全新空库**即自动建表；**勿**把迁移指向已有别的建表方式的旧库（会撞表）。
- [ ] 改表结构流程：改 `server/db/schema.ts` → `npm run db:generate` → 提交 `drizzle/` 新迁移 → 部署即生效。

### 反向代理 / 限流（关键）
- [ ] 进程须置于会注入**可信真实 IP**（`cf-connecting-ip` 或 `x-real-ip`）的反代/网关/CDN 之后。
      否则限流只能依赖可伪造的 `x-forwarded-for`，换 IP 即可绕过限流（刷爆 token）。
- [ ] **多实例 / 无状态扩缩容**：当前默认内存限流按实例独立计数，多实例下失效。
      上量前把 `createApp` 的 `limiter` 换成 `kvRateLimiter`（`server/ratelimit.ts` 已备骨架，
      实现一个 `KVRateStore.hit` 接到 Redis/Upstash 即可，ioredis 与 Upstash 适配示例见文件内注释）。
      Cloudflare Workers 同理（worker.ts 多实例）。注：`app.ts` 内的登录类 `authLimiter` 目前仍为内存，
      多实例若也要分布式，可扩展 `createApp` 额外注入。

### HTTPS / Cookie
- [ ] 全站 HTTPS。会话 cookie 的 `secure` 按请求协议自动设——务必让服务端看到的是 `https:`
      （反代要正确透传协议 / 用 HTTPS 回源），否则 secure 不生效。

### 合规
- [ ] 注销（PIPL 删除权）已做真删 + 事务级联，确认线上可走通「注销 → 云端数据清空」。
- [ ] 合规文案与红线护栏（不预测生死 / 不医疗投资法律定论 / 不改运转运）已在 prompt + 服务端净化两层，
      上线前抽查几条真实输出。

## C. 已在代码内加固（本轮审查，无需手动操作，知悉即可）

- **并发同步丢数据**：`存命盘` 改 SQL 原子 LWW（`onConflict setWhere` + `GREATEST`/`CASE`），
  旧 ts 不再覆盖新 ts；reading 永不被空值清掉。
- **注销事务**：`删用户` 三表删除包进 `db.transaction`，全删或全不删，杜绝部分删除留孤儿。
- **坏行容错**：`/api/charts` 单行 `chartJson` 损坏只跳过该行，不再整体 500。
- **生产兜底**：缺 `DATABASE_URL` 时生产拒启（exit 1）。
- **入站加固**：`读限JSON` 只收非空普通对象（挡 null / 裸数字 / 数组）；体积按真实字节硬卡，不信 `content-length`。
- **外呼超时**：微信 OAuth fetch 8s 超时，避免回调挂起。
- **会话**：token 只存 SHA-256、明文仅发 httpOnly cookie；过期会话启动 + 每日清理。
- **CSRF**：写操作校验同源 Origin + SameSite=Lax + OAuth state 一次性 cookie。

## D. 本地优先的产品事实（知情即可，非缺陷）

- 命盘默认**只存用户设备**（localStorage）。清浏览器数据会丢盘——**除非**用户登录并开启云端同步。
  账号弹窗已有文案说明；这是「本地优先 / 私密」的有意设计，不是 bug。
