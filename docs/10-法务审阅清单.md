# 10 · 法务审阅清单（给法务/合规终审用）

> 工程与产品侧的合规已按 `docs/07` 落地（见下「已落地」）。本清单把**需要法务/合规专业判断**的事项
> 逐条列出，便于法务高效复核、批注、补齐。**勾选完即可视为法务终审通过的前置条件齐备。**
> 文案草稿见 `docs/09-合规文案`；产品内可独立访问的完整版页面：`/terms`、`/privacy`。

## A. 文案终审与占位补齐（草稿里 `〔…〕` 处）
- [ ] 运营主体全称、统一社会信用代码
- [ ] ICP 备案号 / 经营性 ICP（如涉付费）
- [ ] 联系邮箱、电话、办公地址
- [ ] 协议与隐私政策的**生效日期 / 更新日期**
- [ ] 法律适用与**争议管辖地**
- [ ] 《用户协议》：知识产权与 UGC 授权条款、责任限额与赔偿上限（须符合强制性规定）
- [ ] 《隐私政策》：存储期限、是否跨境、与各处理者的实际口径一致

## B. 定性与红线（封建迷信 / 内容安全）
- [ ] 确认对外定位「传统文化体验 / 自我探索 / 文化娱乐」措辞无「算命 / 占卜 / 预测命运」硬伤
- [ ] 六爻（占卜类）专项：确认「梳理思路的镜子、不预测吉凶、不报死应期」的定位足以过审（最敏感）
- [ ] 抽查若干真实 AI 输出，确认未触红线（生死/疾病/灾祸预测、改运消灾、决定论、医疗投资法律定论）
- [ ] 确认 `server/compliance.ts` 净化词表覆盖面（营销迷信词 + 兜底）符合预期

## C. 个人信息 / PIPL
- [ ] 确认收集项（出生日期/时间/地点/性别）的告知-同意充分；是否构成敏感个人信息需单独同意
- [ ] **与 DeepSeek 签数据处理 / 委托处理协议**，据实改写隐私政策「第三方共享」（留存/训练口径）
- [ ] 微信登录授权范围、隐私链接合规
- [ ] 注销「真删」流程符合删除权要求（工程已实现事务级联真删，法务确认告知一致）
- [ ] 未成年人条款与年龄判定方式是否满足监管期望

## D. 渠道 / 上架 / 备案
- [ ] ICP 备案（网站）/ 应用商店主体资质
- [ ] 应用商店类目按「传统文化 / 工具 / 生活方式」申报；标题、描述、截图无敏感词
- [ ] 生成式 AI 服务相关：确认所用大模型（DeepSeek）为**已备案**模型；如有算法备案/大模型上线备案要求逐一确认
- [ ] 各渠道（App Store / 安卓商店 / 微信生态）审核要求逐一确认，准备降级包装预案

## E. 广告 / 营销（如启用）
- [ ] 不使用绝对化用语、不宣称「预测准确 / 包准」；不以恐惧诱导付费
- [ ] 付费点（如有）不与「改运 / 消灾 / 解厄」绑定

## 已落地（工程/产品侧，供法务知悉，无需法务操作）
- 首次「告知-同意」门（未成年人 + AI 生成 + 免责），本地记录同意。
- AI 生成内容显著标识贯穿全部出口（解读/追问/流年/深度/解梦/六爻）。
- 红线护栏双层：各 prompt 明确禁区 + `server/compliance.ts` 确定性净化器兜底。
- 对外 meta 措辞去「命理 App」硬框架，统一传统文化/自我探索/文化娱乐。
- 隐私工程：本地优先、注销事务级联真删（PIPL 删除权）、令牌仅存哈希、HTTPS、密钥不入日志。
- 可独立访问的完整《用户协议》《隐私政策》页（`/terms`、`/privacy`）+ 产品内摘要。
- 大陆版使用境内备案大模型 DeepSeek（符合《生成式 AI 办法》），勿换未备案境外模型。
