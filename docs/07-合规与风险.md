# 07 · 合规与风险

> 国内对"算命/封建迷信"敏感。合规不是上线前补丁，是从第一天起的架构约束。
> 本文档列红线、措辞规范、上架策略。**非法律意见，落地前需专业法务复核。**

## 1. 核心风险

- **监管定性**：宣扬封建迷信在国内是明确受限内容。措辞和定位不当会被下架/处罚
- **平台审核**：微信小程序、App Store、应用商店对"算命"类目审核严格，常直接拒
- **内容风险**：AI 生成涉及生死/疾病/灾祸的预测 → 既违规又可能造成真实伤害
- **付费风险**："花钱改运/消灾"类交易触碰诈骗/迷信红线

## 2. 定位与措辞规范

### 对外定位（一致使用）
✅ 传统文化 · 命理文化 · 性格分析 · 自我探索 · 国学

### 措辞红线（产品文案 + AI 输出都适用）
| ❌ 禁用 | ✅ 替代 |
|---|---|
| 算命 / 预测命运 | 传统文化解读 / 性格分析 |
| 改运 / 转运 / 消灾 / 化解 | （不提供，整类砍掉） |
| 吉凶 / 凶兆 / 大凶 | 倾向 / 需留意 / 这套系统认为 |
| 你注定 / 命中注定 | 可能 / 倾向于 / 传统命理认为 |
| 预测生死 / 寿命 / 重病 | （绝对禁区,见 §3） |
| 风水化煞 / 开光 / 法事 | （不碰） |

## 3. AI 输出绝对禁区（硬拦截）

这些不只是措辞问题，是底线：
- ❌ 预测**死亡时间 / 寿命 / 重大疾病 / 灾难事故**
- ❌ 把命理当**医疗/法律/投资**确定建议
- ❌ 用恐惧逼迫付费
- ❌ 决定论断言（取消用户的能动性）

**实现**（双层，不靠模型自觉）：
1. system prompt 明确禁区清单
2. 输出层关键词 + 语义二次校验，命中则改写或拦截
3. 健康话题统一加"请以专业医疗意见为准"，不下诊断

## 4. 上架 / 渠道策略

- **类目伪装**：以"传统文化/工具/生活方式"类目申报，避免"占卜算命"敏感词
- **关键词卫生**：商店标题、描述、截图不出现"算命/占卜/预测"
- **微信小程序**：审核尤其严，可能需要先 Web/App 验证，小程序作为后续渠道评估
- **降级预案**：若某渠道拒审，产品核心（自我探索/性格分析）应能以更"软"的包装存活

## 5. 内容与数据合规

- **个人信息**：生辰、出生地属个人信息，需合规存储 + 隐私政策（隐私不能埋，要显著告知）
- **未成年人**：评估是否限制 / 年龄门
- **免责声明**：明确"娱乐 / 文化参考,非科学预测",但放在合适位置不扫体验

## 6. 品牌风险（软性但致命）

- **不贩卖焦虑**：靠恐惧变现短期有效长期毁品牌，也最招监管。坚决不做
- **诚实可信**：流派选择透明、不假装唯一真理、不夸大"准"到神棍程度

## 8. 六爻 / 占卜类专项（最敏感，单列）

占卜算卦是「封建迷信」里被点名最直接的一类，比八字/紫微更需小心：
- **定位**：卦是「换个角度梳理思路的镜子」，不是预测吉凶、不替用户做决定（prompt + view-lead 已收紧）。
- **措辞**：不报死应期/某天必应；「应期」一律柔性化为「传统上会留意某个时段，仅作参考」。
- **红线同八字**：不预测生死灾祸、不医疗投资法律定论、不改运消灾（liuyaoPrompt 已含，compliance.ts 兜底）。
- **渠道**：商店描述/截图避免「占卜/算卦/预测」字样，统一「传统文化体验」。
