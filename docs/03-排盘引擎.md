# 03 · 排盘引擎

> 这是产品信誉的地基。**盘错即死。** 本文档列出计算细节、易错点、对账策略。
> 原则：不自己造天文轮子，用成熟历法库 + 命例对账。

## 1. 公共基础：历法与天文

所有排盘都依赖这层先算对：

- **公历 ↔ 农历转换**：用 `lunar-typescript`，不自己实现（涉及天文月相）
- **儒略日 (JD)**：日柱靠连续日数推干支，必须有准确 JD
- **二十四节气**：八字换月、紫微部分规则都依赖。节气是太阳黄经到达特定度数的**精确时刻**，需天文计算（库已内置）
- **真太阳时校正**（重要差异化）：
  - 钟表时间 = 北京时间（东经 120°），出生地经度不同有时差（每度 4 分钟）
  - 加均时差（equation of time，全年 ±16 分钟）
  - 真太阳时可能跨过时辰边界 → 改变时柱，必须支持

## 2. 八字排盘

### 2.1 四柱

| 柱 | 依据 | 易错点 |
|---|---|---|
| 年柱 | **立春**为年界 | ❌ 不是元旦 ❌ 不是正月初一。立春前算上一年 |
| 月柱 | **节气**换月（12 节令）+ 五虎遁定月干 | ❌ 不是农历月。交节当天要看精确时刻 |
| 日柱 | 连续干支日（靠 JD） | 子时换日规则（见 2.3） |
| 时柱 | 时辰 + 五鼠遁（由日干推时干） | 真太阳时是否跨时辰；子时拆分 |

### 2.2 每柱要算出
- 天干、地支
- 地支**藏干**（本气/中气/余气）
- **纳音**五行
- **十神**（以日干为我，推其余干支的十神关系）

### 2.3 必须明确的**教法选择**（不同流派结论不同，要做成可配置 + 默认值）
- **早子时 / 晚子时**：23:00–24:00 算今日晚子时还是次日早子时？→ 影响日柱。默认建议：晚子时归当日、日干用次日（或做成选项并说明）
- **真太阳时**：默认开启还是默认关闭？建议默认按出生地经度校正，UI 可关
- **节气交接当天**：以精确时刻判定，库已处理
> 这些不是 bug 是流派差异。产品要**选一个默认 + 透明告知 + 允许切换**，不能装作只有一个答案（违反"UI 不能撒谎"）。

### 2.4 衍生盘
- **五行旺衰统计**（含藏干加权，权重方案要透明可查）
- **大运**：起运岁数（按出生到下一/上一节气的天数换算）+ 顺逆排（阳男阴女顺、阴男阳女逆）
- **流年**、**神煞**（神煞流派极多，明确收录哪些、出处）

## 3. 紫微斗数排盘

### 3.1 输入
- **农历**生月、生日 + 时辰 + 性别（紫微用农历，与八字用节气历不同，别搞混）

### 3.2 安盘步骤（顺序敏感，错一步全盘错）
1. **定十二宫**：由生月、生时定命宫地支，顺布十二宫（命/兄弟/夫妻/子女/财帛/疾厄/迁移/交友/官禄/田宅/福德/父母）
2. **定身宫**
3. **定五行局**（纳音，由命宫干支得水二/木三/金四/土五/火六局）
4. **安紫微星**：由五行局 + 农历生日定紫微落宫
5. **安十四主星**：紫微系 + 天府系按固定规则排
6. **安辅星 / 煞星 / 杂曜**：左辅右弼、文昌文曲、擎羊陀罗、火铃、化禄权科忌等
7. **四化**：由**生年天干**定化禄/化权/化科/化忌落于哪颗星
8. **大限**（每宫十年）、**流年**、**流曜**

### 3.3 实现策略
- 紫微现成 JS 库质量参差，**很可能需要自实现安星 + 严格对账**
- 安星规则是确定性查表/口诀，适合纯函数实现
- 农历数据从 `lunar-typescript` 取，避免自己算农历

## 4. 对账策略（上线前硬门槛）

**没有对账通过，引擎不许接入产品。**

1. **命例库**：收集 N 个已知正确命盘（权威排盘软件如专业八字/紫微软件的输出、命理书籍例题）
2. **黄金测试**：每个命例写成单测，断言四柱/藏干/十神/紫微各宫主星完全一致
3. **边界命例必测**：
   - 立春前后出生（年柱边界）
   - 交节当天出生（月柱边界）
   - 子时出生（日柱/时柱边界）
   - 闰月出生（紫微农历月）
   - 真太阳时跨时辰
   - 极早/极晚年份（历法库覆盖范围边界）
4. **跨库交叉验证**：八字结果和紫微所依赖的农历，互相印证一致

## 5. 引擎接口（草案）

```ts
type 排盘选项 = {
  历法: '公历' | '农历'
  闰月?: boolean
  时辰: number          // 0-23 或时辰索引
  性别: '男' | '女'
  出生地?: { 经度: number; 纬度: number }  // 真太阳时用
  真太阳时校正?: boolean   // 默认 true
  子时规则?: '晚子时归当日' | '晚子时归次日'  // 默认待定
}

function 排八字(年,月,日, 选项): 八字命盘JSON
function 排紫微(年,月,日, 选项): 紫微命盘JSON
```

详细 JSON 结构见 [05-命盘数据模型](05-命盘数据模型.md)。

## 6. 引擎纪律

- 纯函数、无网络、无副作用 → 可单测可复现
- 所有流派选择**显式参数化** + 有文档化默认值，绝不在代码里偷偷选一派装成唯一真理
- 任何权重/口诀/规则在代码注释里标出处
- 引擎是命门，宁可慢一点也要对
