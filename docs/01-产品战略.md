# 01 · 产品战略

## 1. 是什么

一个 AI 驱动的中文命理产品，用八字和紫微斗数帮年轻人**认识自己**。
不是预测未来的算命摊，是用一套古老符号系统做的、有温度的自我探索工具。

**类比定位**：东方版 Co-Star / The Pattern，但底层是真正的命理引擎，不是星座泛泛而谈。

## 2. 给谁

- **核心**：国内 18–30 岁年轻人，城市，女性偏多（命理类付费主力）
- **心理画像**：对命运/性格好奇，焦虑但理性，玩过星座 MBTI，对"准不准"敏感，反感爹味说教和封建迷信腔
- **不是给谁**：硬核命理老炮（他们要专业排盘软件，不要 AI 解读）；信"改运消灾"的中老年（监管雷区，也不是我们的人）

## 3. 为什么是现在 / 为什么是我们

- 星座/MBTI 已经把"用符号系统认识自己"教育成了主流娱乐，但**东方命理还停在 PDF 报告和九宫格静态文案**的体验石器时代。
- LLM 第一次让"千人千面的个性化解读 + 可对话追问"成为可能——这是静态报告做不到的。
- 体验差距 = 机会。市面 90% 产品要么盘不准、要么解读是模板拼接、要么 UI 像 2010 年。

## 4. 核心差异化（护城河优先级）

1. **解读体验**（最高）：对话式、个性化、有人味。这是 LLM 时代唯一能拉开代差的地方。
2. **引擎准确**（地基）：不是差异化，是入场券。盘错直接出局。
3. **审美 / UX**：年轻人吃这套，是留存和传播的杠杆。
4. **不贩卖焦虑的品牌人格**：长期信任，区别于贩卖焦虑的同行。

## 5. 商业化（方向，非定稿）

- **免费**：基础排盘 + 一段核心解读（建立"准"的认知，制造 wow）
- **付费**：深度解读（事业/感情/财运专题）、大运流年、AI 持续对话追问、双系统对照（八字×紫微）
- **形态**：订阅优先于单次买断（命理是长期陪伴，不是一锤子买卖）
- **反模式**：不做"花钱算你有没有灾"——既踩监管又毁品牌

## 6. 合规包装（详见 [07-合规与风险](07-合规与风险.md)）

对外一律用：**传统文化 · 性格分析 · 自我探索 · 命理文化**。
对外禁用：算命、预测、改运、消灾、吉凶、生死病灾、风水化解。
这不只是文案，是写进 AI prompt 的硬约束。

## 7. 北极星与早期信号

- **北极星**：能不能让用户看完解读后说出"这也太准了 / 这说的就是我"。
- **早期验证信号**（按可信度排序）：自发分享解读截图 > 主动追问更多 > 完成完整生辰输入 > 注册。
- **刻意不追的虚荣指标**：算过几次、连续打卡天数、好友排行（见 [社交货币 ≠ vanity metrics] 原则）。

## 8. 当前假设（需验证，勿当事实）

- 假设：国内年轻人愿意为"准且有人味"的命理解读付费订阅。
- 假设：八字+紫微双系统的"专业感"是信任来源而非认知负担。
- 假设：合规包装足以让产品在小程序/应用商店存活。
- 这些都是假设。MVP 的存在就是为了证伪它们。
