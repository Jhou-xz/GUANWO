# 06 · UX 与用户旅程

> "体验拉满"是这个产品的命题。引擎是地基，UX 是用户唯一摸得到的东西。
> 核心目标：让用户看完第一段解读说出"这也太准了"。

## 1. 体验原则

- **快**：盘秒出（确定性计算+缓存），命盘可视化先于 AI 文字
- **美**：东方美学但年轻化，不是道观风也不是星座号大字报
- **有人味**：解读像朋友发来的长消息，不像系统报告
- **不焦虑**：全程没有"你有灾/快付费消灾"的恐吓
- **诚实**：流派选择、传统文化定位透明，UI 不撒谎

## 2. 主旅程（首次使用）

```
1. 落地 / 钩子
   ↓  一句话价值主张,不剧透到无聊。无需注册先体验
2. 输入生辰   ← 第一个体验关卡,易错点见 §3
   ↓
3. 排盘动画 / 命盘揭晓   ← 第一个 wow:盘"长出来"的仪式感
   ↓
4. 核心解读(免费)   ← 决定生死的一屏:必须"准"且"懂我"
   ↓
5. 追问 / 深入   ← 对话式,自然引导到专题
   ↓
6. 付费转化   ← 价值已被证明后才出现,不是一上来就要钱
```

## 3. 输入生辰（最容易流失，要重点设计）

命理输入天然反人性，是最大流失点。设计要点：
- **公历/农历切换**，默认公历（年轻人记公历多）
- **不知道时辰怎么办**：这是高频痛点。给"时辰对照说明" + "不确定"选项（说明会影响精度，可后补）
- **出生地**：为真太阳时校正，做成可选 + 解释为什么问（"为了算得更准"）
- **闰月**：农历模式下要能选
- **别一次问太多**：分步引导，每步只问一件事，降低放弃率
- 输入完成 = 最强早期信号之一，要打磨到顺滑

## 4. 命盘可视化

- **八字**：四柱排盘表（干支/藏干/十神/纳音），信息密度高但要可读
- **紫微**：十二宫圆盘/方盘（传统命盘样式但现代化排版）
- 可视化**即时渲染**（不等 AI），给用户"东西真算出来了"的实感
- 命盘元素**可点**：点某柱/某宫 → AI 就这部分展开解读（呼应"Avatar 必须能点"的交互哲学）

## 5. 解读呈现

- **流式输出**：像朋友正在打字，不是 loading 转圈后甩一坨
- **分段可读**：总览 → 分块（性格/事业/感情…），不是一大坨
- **首屏即 wow**：最准、最戳的那句放最前
- **对话入口常驻**：随时能追问

## 6. wow 时刻设计（产品的核心赌注）

第一段解读是整个产品的生死点。它必须让用户感到"被看见"：
- 用盘里**具体配置**说出一个用户私下认同但没对人说过的特质
- 避免"换谁都成立"的废话（星座号通病）
- dry/deadpan 的精准 > 华丽的空洞

## 7. 留存与回访（非首次）

- **流年/大运**：天然的回访理由（"今年对你意味着什么"），但不靠制造焦虑
- **持续对话**：命盘常驻，随时来聊新困惑
- **刻意不做**：打卡天数、算命次数、好友排行等虚荣指标（见社交货币原则）

## 8. 待决策

- 视觉风格定调（东方现代 / 极简 / 插画感？）需出 moodboard
- 命盘可视化的具体样式（传统盘 vs 重新设计）
- 首屏免费解读给到多长
- 是否要 AI 人设的视觉形象出现在对话里
