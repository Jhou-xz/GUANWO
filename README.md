# AI 命理（暂名）

[![CI](https://github.com/Zachpyo/ai-suanming/actions/workflows/ci.yml/badge.svg)](https://github.com/Zachpyo/ai-suanming/actions/workflows/ci.yml)

一个体验拉满的中文命理产品。核心命题：**引擎像瑞士钟表一样准，AI 像老朋友一样懂你。**

- **MVP 范围**：八字 + 紫微斗数（七政四余列入 v2，需真实星历）
- **目标用户**：国内年轻人，中文，chill、不装神弄鬼
- **形态**：先 Web demo 验证「盘准 + 好看」，引擎纯 TS 可多端复用

## 跑起来

```bash
npm install
npm run dev      # 起 http://localhost:5180  （加 ?demo=1 自动起样例盘）
npm test         # 引擎对账测试（八字四柱 / 立春边界 / 紫微 / 农历）
```

技术栈：Vite + React + TS；八字 `lunar-typescript`、紫微 `iztro`。代码结构：
`src/engine/`（纯函数排盘引擎 + 对账测试）· `src/components/`（命盘可视化）· 东方极简样式见 `src/styles.css`。

## 一句话架构

排盘（确定性天文历法计算）和解读（AI）**物理隔离**，中间用一份 **命盘 JSON** 当唯一契约。AI 只读这份 JSON，绝不自己算干支。

```
用户输入生辰
   ↓
[排盘引擎]  ← 确定性，必须 100% 准，拿命例对账
   ↓ 命盘 JSON（唯一契约）
[AI 解读层]  ← 朋友人设，对话式，禁吉凶/生死/改运
   ↓
[前端体验]  ← "体验拉满"的主战场
```

## 设计原则（贯穿全产品）

1. **盘错即死。** 引擎准确性是信誉的地基，懂行用户盘一错当场就走。
2. **AI 是翻译官，不是算命先生。** 把冷命盘翻译成温暖、个性化、对话式的解读。
3. **不贩卖焦虑。** 不靠"你命里有灾"逼用户付费。社交货币 ≠ 制造恐惧。
4. **dry / deadpan / chill。** Gen Z voice，不装神弄鬼，不搞煽情纪录片腔。
5. **合规先行。** 传统文化 / 自我探索定位，措辞禁区写进 prompt。
